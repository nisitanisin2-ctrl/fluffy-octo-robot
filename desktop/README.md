# パソコン用アプリ版

**アプリの中に地図を開いて、載せたい範囲をそのまま用紙に貼り付けられます。**
Win+Shift+S で画面を切り取る手間がいりません。

ブラウザ版（`index.html` をダブルクリック）は今までどおりです。この中身はブラウザ版には一切影響しません。

## 起動

いちばん上のフォルダにある **`パソコン用アプリを起動.bat`** をダブルクリックしてください。
はじめの1回だけ、必要なもの（Electron）を自動で入れるので5分ほどかかります。2回目からはすぐ開きます。

コマンドから動かす場合は、このフォルダで

```bash
npm start
```

## 使い方

1. 上の **「🗺 地図を開く」** を押す … アプリの中に Google マップが出ます
2. 住所や現場名を入れて **Enter**（Googleマップのアドレスを貼り付けてもOK）
3. 地図を動かして、用紙に載せたい範囲を画面に出す
4. **「⬛ 範囲を選ぶ」** → 地図の上をドラッグして四角で囲む（囲まなければ画面全体）
5. **「📌 この範囲を貼り付ける」** → 用紙に地図として入り、そのまま矢印が引ける状態になります

- **「★ 登録」** … よく使う場所に名前を付けて残せます。次からは一覧で選ぶだけです
- **Esc** … 地図の画面を閉じます

## 中身

| ファイル | 役目 |
| --- | --- |
| `main.js` | 窓を開いて、ひとつ上のフォルダの `index.html` をそのまま表示します |
| `preload.js` | 「🗺 地図を開く」ボタンと、地図の画面（範囲を選んで切り取る所）を後から足します |
| `package.json` | Electron の指定 |

**`index.html` は書き換えていません。** アプリ本体を直すと、パソコン用アプリ版にもそのまま反映されます。

`node_modules`（Electron 本体、約200MB）は GitHub には上げていません。`npm install` で入れ直せます。

## ご注意

地図画像は Googleマップの利用規約の範囲内でご利用ください。画面の著作権表示ごと切り取っておくのがおすすめです。
