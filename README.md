# 現場経路作成アプリ

Googleマップやヤフー地図のスクリーンショットに、**赤い矢印で経路**を描き、**曲がり角や入口の写真**を差し込んで、現場までの道順図を作るアプリです。

`index.html` ひとつだけで動きます。インストール不要・オフラインで動作し、地図や写真がどこかに送信されることはありません（すべてブラウザの中だけで処理されます）。

はじめから **A4 用紙（初期は横向き）の枠** が表示されるので、印刷したときの仕上がりを見ながら作れます。

## パソコンに入れる（インストール）

**アプリの画面はこちら → https://nisitanisin2-ctrl.github.io/fluffy-octo-robot/**

上のページを Chrome または Edge で開き、**アドレスバーの右端に出るインストールの印（「⊕」や、画面から矢印が出ているようなマーク）** を押して「インストール」を選ぶと、

- デスクトップとスタートメニューにアイコンができます
- 次からはそのアイコンから、**ブラウザの枠なし・ひとつのアプリとして**開きます
- 一度入れておけば、**インターネットにつながっていなくても使えます**（アプリ本体が端末に保存されます）
- アプリを直したときは、次に開いたときに自動で新しくなります

> 印が見当たらないときは、`⋮` メニュー →「キャスト、保存、共有」→「ページをアプリとしてインストール」から入れられます。すでにインストール済みの場合は出ません。
>
> スマホ（Android の Chrome）でも同じように「ホーム画面に追加」で入れられます。iPhone の Safari は「共有」→「ホーム画面に追加」です。

インストールせず、`index.html` をダウンロードしてダブルクリックで開く従来の使い方もそのままできます。

## パソコン用アプリ版（アプリの中に地図が出ます）

**`パソコン用アプリを起動.bat`** をダブルクリックすると、**アプリの中に Google マップが開く版**が立ち上がります。

1. 「🗺 地図を開く」→ アプリの中に地図が出ます（住所や現場名で検索できます）
2. 載せたい範囲を画面に出して「⬛ 範囲を選ぶ」→ ドラッグで囲む
3. 「📌 この範囲を貼り付ける」→ 用紙に入り、そのまま矢印が引けます

<kbd>Win</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> で切り取る手間がいりません。よく行く現場は「★ 登録」で残せます。
くわしくは [desktop/README.md](desktop/README.md) をご覧ください。ブラウザ版は今までどおりで、何も変わりません。

## 使い方

1. アプリを開く（インストールしたアイコン、または上のページ。`index.html` を直接ダブルクリックでも可。Chrome / Edge 推奨）
2. Googleマップやヤフー地図で現場周辺を表示する
3. <kbd>Win</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> を押し（画面が白くなります）、写したい範囲をドラッグで囲む
4. アプリの画面に戻って <kbd>Ctrl</kbd> + <kbd>V</kbd> を押す（青い点線の枠に自動で収まります）
5. 「➜ 矢印」ボタンを押してから、道に沿ってクリックしていき、ダブルクリックで確定
6. 画面右の「差し込み用写真」の枠をクリックしてから <kbd>Ctrl</kbd> + <kbd>V</kbd> で、現場の写真を追加
7. 「印刷」または「画像で保存」で完成

地図を読み込む前は、用紙の中央にこの手順がそのまま表示されるので、覚えていなくても操作できます（この案内は画面上だけの表示で、印刷や画像保存には出ません）。

## 用紙と地図の調整

| 操作 | 場所 |
| --- | --- |
| A4 横 ⇄ A4 縦 の切り替え | 右パネル「用紙」 |
| **地図の大きさを変える** | 右パネル「大きさ」のスライダー（20〜400%）、または「− 小さく」「＋ 大きく」 |
| 地図を枠に収める／枠いっぱいに広げる | 右パネル「枠に収める」「枠いっぱい」 |
| 地図を動かす・つまんで拡大縮小する | 右パネル「✋ 地図をつかんで動かす」→ ドラッグ／枠の右下の □ |
| 地図と下スペースの境目を動かす | 用紙の中央にある橙色のつまみを上下にドラッグ、または右パネルの「高さ」 |
| **「ここに地図を貼り付けます」の案内を消す** | 右パネル「🙈 案内を消す」（もう一度押すと出ます。もともと印刷や画像保存には出ません） |

地図の大きさは「枠に収めたとき＝100%」を基準にした % と、実寸（mm）の両方が表示されます。

- 青い点線が**地図の枠**です。ここからはみ出た部分は印刷されません（拡大して必要な範囲だけ見せられます）
- 灰色の点線は**用紙の余白（10mm）の目安**です。プリンタで切れやすい範囲を避けるための目印です
- **これらの点線は画面上の目安で、印刷や画像保存には出ません**
- 現場名を入力すると、用紙の上に見出しが入ります。**印刷される場所は、現場名の右のプルダウンで「左寄せ・中央・右寄せ」から選べます**（左右の端は用紙の余白 10mm にそろいます）

## できること

| 道具 | 内容 |
| --- | --- |
| ➜ 矢印 | 折れ曲がった経路も一本で描けます。白フチ付きで地図の上でも見やすい表示 |
| ─ 罫線 | **矢印の付かない線**。区域の境目、う回路、敷地の区切りなどに。すぐ右のプルダウンで**実線・破線・長い破線・点線・一点鎖線・二点鎖線**から選べます |
| 🛣 道 | **2本の線（2重線）で道を描きます**。道の真ん中をクリックしていくと、両側に線が引かれます。線の太さは「太さ」、線と線の間は**すぐ右の「道幅」**（とても狭い〜最大の6段階）で選べます。折り返しなど、道が自分と重なる所では**道の中に入る線が消えて**、1本の道としてつながって見えます |
| 📍 番号ピン | 1・2・3… と自動で番号が付きます。写真の番号と対応させて使います |
| 👮 警備員 | 警備員の立ち位置を示すピン。文字は「誘導員」などに変更できます |
| 🚿 洗い場 | ミキサー車（生コン車）のシュートを洗う場所を示すピン。文字は「2号洗い場」などに変更できます |
| ◯ 丸囲み / □ 四角囲み | 目印や入口、資材置場などを囲みます。四角は、すぐ右のプルダウンで**「吹き出し」**を選ぶと、指したい場所へ細いでっぱりが付きます（先端の黄色い □ をドラッグして向きを変えられます） |
| ✎ 文字 | 「この先 入口」などの注記。あとから移動・拡大縮小できます |
| 🖼 写真 | 曲がり角や入口の写真を配置。**番号**で示すか、**吹き出し**で場所を直接指すか選べます |

- 色は赤・青・緑・オレンジ・黒
- 「太さ」が効くのは**線だけ**（矢印・罫線・道・丸・四角）です。9段階（極細〜極太）あり、細めの「標準」から始まります
- **ピンと文字は、太さを変えても大きさが変わりません。**細い線で描いてもピンが小さくならないようにしてあります。個別に大きさを変えたいときは、「選択」でつまんで右下の □ をドラッグしてください
- **「⌒ カーブを丸くする」**にチェックを入れて矢印・罫線・道を引くと、曲がり角が角ばらずになめらかなカーブになります。引いたあとでも、「選択」でその線をクリックしてからチェックを切り替えれば、線ごとに変えられます（曲がり角の少し手前から曲がり始めます）
- 濃さ（透明度）は6段階。う回路や区域の囲みを薄く細く描くと、本線の経路が目立ちます
- ピンの色は、置く前に選んでいる色ボタンの色になります。置いたあとに色ボタンを押して変更することもできます
- 開いたときは「🖱 選択」から始まります。うっかり線が引かれないので、まず地図を貼る・位置を直すといった作業から入れます
- 「選択」ツールで、書き込みをドラッグして移動、右下の □ で拡大縮小
- 矢印と罫線は曲がり角の □ をドラッグして、線の形だけを直せます
- 引いたあとの罫線を「選択」でつまんでから、プルダウンで種類を変えることもできます
- 吹き出し写真は、先端の黄色い □ をドラッグして指す場所を変えられます
- 元に戻す / やり直す（<kbd>Ctrl</kbd> + <kbd>Z</kbd> / <kbd>Ctrl</kbd> + <kbd>Y</kbd>）に対応

## 下のスペース

用紙の下部に、文言や写真を入れるスペースを確保できます。高さは **mm 単位** で調整できます。

- 集合時間・注意事項・連絡先などの**文言を入力**すると、そのスペースに印刷されます
- **「この高さに文言は約○行／写真に使える高さ約○mm」**と表示されるので、どれくらい入るか決めながら高さを調整できます
- 文字の大きさは 小・中・大 から選べます
- 「写真を下のスペースに並べる」ボタンで、用紙に置いた写真をまとめて下へ移せます（文言の下に、用紙の余白 10mm の内側に収まるように並びます）
- 写真は個別にドラッグしても、地図と下スペースの間を自由に行き来できます

## 印刷について

用紙は A4・150dpi で作られており、印刷ダイアログで**用紙サイズ A4**・**余白なし**・**倍率 100%（等倍）**を選ぶと、画面どおりの大きさで印刷されます。

## 保存

- **画像で保存** … PNG画像として書き出します
- **印刷** … 現場名を入れると印刷時のタイトルになります
- **保存 / 開く** … 作りかけの状態を `.route.json` として保存し、後日続きから編集できます（地図と写真もこのファイルの中に入ります）

## バージョン

**画面の右下**に、今お使いのバージョンと更新日が出ます（例：`バージョン 1.2（2026-07-28）`）。マウスを乗せると、インストール済みかブラウザで開いているかも分かります。この表示は画面上だけで、印刷や画像保存には出ません。

「直したはずなのに変わらない」というときは、まずここの日付をご確認ください。

> 作る側の方へ：アプリを直したら `index.html` の `APP_VERSION` / `APP_DATE` と、`service-worker.js` の `CACHE` 名の3か所をそろえて新しくしてください。名前が変わることで、インストール済みの端末でも古い保存版が捨てられ、確実に新しい版に入れ替わります。
